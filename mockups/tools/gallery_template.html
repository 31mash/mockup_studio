Every shot also exists as a transparent PNG with its shadow, for placing on any colour, in mockups/renders/ of the repository, beside these JPGs.

Artwork is redrawn as vector from the spread, which is a low-resolution photo. Where the spread doesn't show a side, its print is new copy in the same style. To use the original print files instead, replace the PNGs in each product's art/ folder and render again.
